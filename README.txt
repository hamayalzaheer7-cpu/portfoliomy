HAMAYAL ZAHEER PORTFOLIO

Static HTML, CSS and JavaScript website. Open index.html to preview locally.

VERCEL DEPLOYMENT
1. Upload these files to a GitHub repository.
2. In Vercel, choose Add New > Project and import that repository.
3. Framework Preset: Other. Leave Build Command blank. Set Output Directory to .
4. Click Deploy.

No build step is required. Homepage: index.html.
